🎨 Color Palette Generator

A simple and interactive Color Palette Generator built with HTML, CSS, and JavaScript.

✨ Features

- Generate random color palettes.
- Display colors with their HEX codes.
- Copy color codes to the clipboard.
- Simple and responsive user interface.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🚀 How to Use

1. Open the project in your browser.
2. Generate a random color palette.
3. Copy the HEX code of your favorite color.

📂 Project Structure

- "index.html" — Page structure.
- "style.css" — Styling and layout.
- "script.js" — Color generation and interactions.

🎯 Purpose

This project was created to practice JavaScript, DOM manipulation, and working with colors.
